기존 GPIO 직결

추가 모터/릴레이 절연모듈과 고정판 제거. D4/D5/A2와 D12/D10/D9/A4를 기존 입력에 직결합니다.

P0/G0 공통

G0.4→L298 GND 기준선으로 공통입니다. 자석−까지 갈바닉 절연된 설계가 아닙니다.

전력 귀환은 별도

모터/자석/코일 전류가 Arduino/센서 귀환에 직렬로 흐르지 않게 분기합니다.

기존 센서선 보존

추가 센서판 없음. 기존 핀·귀환·출력전압을 대조합니다.

자석 다이오드만

별도 접속PCB 없이 릴레이 근처에 각 자석 두 선 사이로 병렬 고정합니다.

기존 오디오/표시

MP3/홍싱 라인·GND 직결과 기존 LED·2초 진행 버튼을 유지합니다.

기존 HW 보존 + 외부 조작부 추가

RFID 소형 배치 · 릴레이 A/B · L298N · KT403A · HONGXING · 기존 센서/부하.

추가 GPIO 절연모듈/고정판 없음. 자석 다이오드3개, 기존 센서/오디오/모터/릴레이 직결입니다.

검증 범위

원본/10ms안의 시험에 더해, 외부 LED의 실제 595 래치 값·2초 버튼·누름 유지/바운스·타이머 대기·정상 센서 진행을 AVR로 시험했습니다.

MP3는 API 대역입니다. 실물 전류·전원 노이즈·접점·모터 역학·센서 인터페이스는 현장 검증이 필요합니다. 하드웨어에는 아직 업로드하지 않았습니다.
