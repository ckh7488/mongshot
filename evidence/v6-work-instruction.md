# 작업지시서 — 배전함 v6 "비절연 스타" 배선안 추가 + 배선 그림 작성

대상: `http://127.0.0.1:8766/` (MONG SHOT · 배전함 설계와 Arduino 시뮬레이터) 를 만든/관리하는 작업 에이전트
작성 기준일: 2026-11-04

---

## 0. 한 줄 요약

기존 **v5(P0/G0 절연안)는 그대로 보존**하고, 그 옆에 **v6 "비절연 스타안"** 을 새 변형으로 추가한다. v6의 결선표(넷리스트)·배선 그림(2D 정면 + 3D 덕트 경로)·자동 검사를 만든다. 부품은 v5에서 **빼기만** 하고 새로 추가하지 않는다.

---

## 1. 왜 v6를 만드는가 (되돌리지 말 것)

- 현장에서 **Arduino ↔ L298N을 직결(GND 공통)** 한 현재 상태로 지금까지 오동작이 없었다.
- v5의 절연(ISO-M, ISO-R, 절연 DC/DC)은 "필요하다고 확인된" 것이 아니라 예방 목적이었다. 절연이 필요한지는 아직 판단 근거(아래 U2 센서 출력 형식 등)가 없다.
- 그래서 **실제로 동작 중인 직결 구조를 정리된 스타 배선으로 만든 안(v6)** 을 기본 비교안으로 둔다. 절연이 나중에 필요하면 v6의 제어 케이블 2개 중간에 절연기를 끼우는 것으로 v5에 가까워진다.
- 배선 원칙: 분배블록(판)은 전압차가 없는 "한 점"이다. 문제가 되는 것은 판에서 장치까지 가는 **선**이고, 다음 두 가지만 지키면 된다.
  1. **짝지어 가기**: 각 전원 +와 그 −, 각 신호와 그 GND를 같은 경로·같은 케이블로 보낸다(루프 면적 최소).
  2. **나눠 뽑기**: 모터·자석 같은 큰 전류의 귀환과 Arduino 쪽 로직 GND가 같은 선을 공유하지 않게 판에서 따로 뽑는다(공통 임피던스 제거).

## 2. v5 대비 변경점

| 구분 | v5 | v6 |
|---|---|---|
| 로직 5V 전원 | 절연 DC/DC (DDR-15G-5) → 5L/G0 | **삭제**. 비절연 5V 강압기 1대(기존 Pololu D36V50F5 #4091)로 통합 |
| 부하측 5V | #4091 → 5D/P0 | 위 강압기 하나가 **5V판 / G판** 을 만듦 (5D·5L 구분 없앰) |
| GND 판 | P0, G0 (서로 연결 없음) | **P0(전력 0V, 스타점)**, **G(로직 0V)**. G는 **강압기 GND를 통해서만** P0와 연결 |
| 모터 신호 | Arduino → ISO-M → L298 | **ISO-M 삭제**. Arduino → L298 직결 + 기준 GND선 동봉 |
| 릴레이 신호 | Arduino → ISO-R → RY-A | **ISO-R 삭제**. Arduino → RY-A 직결 (VCC/GND 동봉) |
| 기타 삭제 | — | 절연부 10kΩ 14개, GPIO 절연 고정 PCB(PCB-IF) |
| P12/P0 판 위치 | 상부함 | **하부함 릴레이·L298 옆으로 이동 권장** (아래 R10) |

유지: SMPS, 차단기, PE, 홍싱(기존 어댑터), KT403A, RY-A/B, L298N, 자석 다이오드(1N5408 ×3), 도어 LED·버튼 패널(J7), 기존 센서 배선.

## 3. 결선표 (v6 넷리스트) — 이 표를 그대로 페이지의 v6 표로 만들 것

### 3-1. 전원 트렁크·보호접지

| 라벨 | 시작 | 끝 | 넷 | 비고 |
|---|---|---|---|---|
| TRK-12P | SMPS V+ | P12.IN | +12V | TRK-0과 **같은 경로로 붙여서** (트렁크 페어) |
| TRK-0 | SMPS V− | P0.IN | P0 | 위와 페어 |
| PE-87/88/89 | 기존 PE 접지부 | SMPS FG / 금속 외함 / 금속 도어 | PE | v5 그대로. **귀환 경로로 사용 금지** |
| AC-L/N | 기존 | SMPS | AC | v5 그대로 |

| 포트 | 연결 대상 | 짝(같은 경로) |
|---|---|---|
| P12.1~3 | RY-A CH1~3 COM | 해당 자석의 P0.1~3 귀환과 같은 덕트 |
| P12.4 | L298N **VMS** | P0.4 와 페어. **조건부: U1 확인 전 확정 금지** |
| P12.5 | 5V 강압기 VIN | P0.5 와 페어 |
| P12.6 | RFID +12V (조건부) | P0.6 과 페어 |
| P12.7 | 기타 12V 센서 + (조건부) | P0.7 과 페어 |

### 3-3. P0 판 (전력 0V, ★스타점)

| 포트 | 연결 대상 | 비고 |
|---|---|---|
| P0.1~3 | 자석 1~3 − (현장 페어의 − 가닥) | 자석 +와 원래 꼬임쌍 유지 |
| P0.4 | L298N **GND 나사** | **굵은 선**. 모터 전류 경로 |
| P0.5 | 5V 강압기 GND(입력측) | 이 선이 **G와 P0를 잇는 유일한 경로** |

| P0.7 | 기타 12V 센서 − (조건부) | |
| P0.8~ | 미사용 · **G판 연결 금지** 라벨 | |

### 3-4. 5V 강압기 → 로직 판

| 라벨 | 시작 | 끝 | 비고 |

| 5V.5 | KT403A VCC (CAB-MP3 안) | G.5 | 액자 리드 귀환 (D8 페어) |
| | | G.6 | 책 리드 귀환 (D6 페어) |
| | | G.7 | KT403A GND (CAB-MP3 안) |

### 3-6. 제어 케이블 (신호 + 그 GND를 **한 케이블/한 묶음**으로)

| 케이블 | 내용 (시작 → 끝) | 비고 |
|---|---|---|
| CAB-RLY | D12→RY-A IN1, D10→IN2, D9→IN3, A4→IN4, 5V.2→VCC, G.2→GND | 릴레이 헤더 1열에 그대로. active LOW 전제(U5) |
| CAB-MOT | D4→L298 IN1, D5→IN2, A2→ENA, **G.8→L298 GND 나사** | ENA 상시ON 점퍼 제거. **기준 GND선은 P0판이 아니라 L298 GND 나사에** (P0.4 굵은 선과 같은 나사, 트윈 페룰) |
| CAB-MP3 | D3→KT403A RX, KT403A TX→D2, 5V.5→VCC, G.7→GND | UART 전압범위·직렬저항 필요 여부는 v5 기록대로 확인 |
| AUD | KT403A DAC_L/R/GND → 홍싱 MP3 IN L/R/GND | 기존 결선 그대로 |
| PANEL(J7) | 5V.4, G.4, D11(SER), D13(SRCLK), D7(RCLK), A3(버튼) | v5 그대로, 전원만 5V/G판으로 |

### 3-7. 자석·현장 입력·기타

| 항목 | 결선 | 비고 |
|---|---|---|
| 자석 n (n=1~3) | P12.n → RY-A CHn COM → 선택접점 → 현장 + / 현장 − → P0.n | 다이오드 1N5408을 **릴레이 근처에서 자석 +/− 사이**에. 띠(K)=+, A=− |
| 액자 리드 | 신호 → D8, 귀환 → G.5 | **같은 꼬임쌍** 유지. D8 근처에서 갈라짐 |
| 책 리드 | 신호 → D6(기존 100Ω 보존), 귀환 → G.6 | 같은 꼬임쌍 |
| A0 조명 / A1 열쇠 / A5 RFID | 기존 신호선 → 해당 핀 | **U2 확인 전 확정 금지** |
| 창문 RY-A CH4 | 기존 W0 SELV 회로 그대로 | P0/G 어느 쪽에도 연결 금지 |
| 홍싱 DC | 기존 어댑터 +/− → 홍싱 DC | 어댑터 −는 **오디오 GND 외에는 어디에도 묶지 않음** |
| L298N 5V-EN 점퍼 | VMS=12V면 ON (온보드 78M05가 로직 5V 생성) | VMS가 5V면 OFF + 5V 단자에 외부 5V (U1) |

## 4. 배선 경로 규칙 (그림과 3D 경로에 반영)

- **R1** 모든 전원 가지: +선과 −선을 같은 경로로 붙여서(가능하면 꼬아서) 보낸다.
- **R2** 모든 신호: 자기 GND와 같은 케이블 안에 넣는다. 현장 랜케이블은 **신호 1개당 한 페어(신호+GND)**, 신호를 다른 페어 가닥에 흩어 놓지 않는다.
- **R3** 덕트를 두 그룹으로 나눈다: **전력 덕트**(+12V, P0, 자석 현장선, 모터 출력선) / **신호 덕트**(5V, G, CAB-*, AUD, PANEL, 리드). 교차할 때는 직각으로.
- **R4** G판·5V판은 Arduino에서 5 cm 이내.
- **R5** L298 기준 GND선(CAB-MOT 안)은 **L298 GND 나사**에 물린다. P0판으로 보내지 않는다.
- **R6** G판과 P0판 사이 **직접 선 금지**. 연결은 강압기 GND 경유 1곳뿐.
- **R7** 자석·모터 귀환은 P0로만. G판에 꽂지 않는다.
- **R8** 홍싱 어댑터 −는 오디오 GND 외 연결 금지.
- **R9** 굵기가 다른 두 선을 한 나사에 물릴 때는 단자 허용 굵기 확인 + 트윈 페룰.
- **R10** (권장) P12/P0판을 하부함 릴레이·L298 옆으로 내리고 상부함→하부함은 트렁크 페어(TRK-12P/TRK-0)만. 공간이 안 되면 상부 유지하되, 상하부 사이에서 P12.n/P0.n 짝선이 같은 덕트로 가는지 그림에 표시.

## 5. 그림·화면 산출물 (만들어 달라는 것)

1. **변형 선택에 "v6 비절연 스타" 추가.** v5 화면·데이터는 수정하지 말 것.
2. **2D 정면 배선도** (상부함·하부함 외곽 + 부품 박스 + 선):
   - 선 색: +12V 주황빨강 / P0 진파랑(굵게) / 5V 황토 / G 청록 / 제어 케이블 분홍(굵은 한 줄로 묶어 표시, 케이블 이름 라벨) / 홍싱 전원·오디오 보라 / PE 회색 점선.
   - P0판에 ★스타 표시. 현장선은 함 밖으로 나가는 화살표 + "외부" 라벨로만.
   - 선 교차는 반원(hop)으로 그려 연결 아님을 표시. 연결점은 점(●).
   - 각 선에 3장의 라벨 사용.
3. **3D 뷰**: 기존 덕트 모델을 따라 v6 선 경로 표시. "귀환선" 토글 시 각 가지의 −/GND만 강조. 두 덕트 그룹(R3)을 색으로 구분.
4. **v6 결선표 탭**: 3장 표 + 각 행에 "경로(덕트 그룹)", "케이블 이름" 열 추가.
5. **자동 검사** (배선 그래프 기준, 결과를 화면에 표시):
   - [ ] P0와 G의 연결 경로가 **강압기 GND 1개뿐**인가 (그 외 경로 0개)
   - [ ] P0 귀환(자석 −, L298 GND)이 G판에 연결된 곳이 없는가
   - [ ] 모든 CAB-*·리드 신호 넷이 같은 케이블/페어 안에 GND 도체를 갖는가
   - [ ] 홍싱 어댑터 −의 연결이 AUD-GND 하나뿐인가
   - [ ] PE가 어떤 DC 귀환 경로에도 포함되지 않는가
   - [ ] 조건부 항목(U1, U2)이 "미확정"으로 표시되는가
6. 완료 후 **스크린샷**(2D 배선도, 3D 귀환선 토글, 검사 결과) 첨부.

## 6. 확인 전 확정 금지 항목 (화면에 "미확인"으로 남길 것)

- **U1 모터 정격전압** → VMS 결정. 5V 모터면 **12V 금지**(VMS=5V, 5V-EN 점퍼 OFF, 5V 단자 외부 공급). 참고: L298은 상·하단 합산 약 1.8 V(1 A, typ) 강하가 있어 5V 공급 시 모터에 약 3 V만 걸린다.
- **U2 A0/A1/A5 센서 출력 형식** → 무전압 접점이면 "신호 + G" 페어로 연결. 전압 출력이면 별도 결정(이 지시서 범위 밖).
- **U3 현장 랜케이블**: Cu/CCA, AWG, 길이, 자석 전류. 전압강하 계산기는 v5 것 재사용.
- **U4 섀시 도통**: L298N 방열판(L298 탭=GND=P0)이 금속 백플레이트에 닿는지, 홍싱 외함이 GND(G)와 도통하며 금속판에 고정되는지. 둘 다 PE에 닿으면 G–P0가 섀시로 이어져 R6 위반 경로가 생김 → 검사 항목에 "섀시 경유 경로" 메모.
- **U5 릴레이 보드**: active LOW 여부, JD-VCC 점퍼 상태, RY-B 8채널 기존 용도.
- **U6 Uno USB**: 5V 핀 외부 공급 중 USB를 꽂으면 두 5V가 병렬로 붙을 수 있음 → 프로그래밍 시 외부 5V 분리 여부를 운영 메모로.
- **U7 KT403A UART** 전압 범위·직렬저항.

## 7. 하지 말 것

- v5 삭제·수정 금지 (v6는 별도 변형).
- 새 부품·새 PCB·퓨즈·단자열 추가 금지 (v5에서 빼는 것만 허용).
- 미측정 값(전선 굵기, 전류, 모터 전압)을 확정값처럼 표시 금지. 가정값은 "가정" 표시.
- "절연 확보", "검증 완료" 같은 문구 금지 — v6는 비절연이며 실물 검증 전이다.
- G판과 P0판을 그림상 편의로 잇는 선 그리기 금지.
