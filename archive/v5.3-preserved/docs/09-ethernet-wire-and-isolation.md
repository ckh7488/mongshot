# 9. 이더넷 심선과 부하 배선

동일 이더넷 외피 안의 가는 선이라는 이유만으로 정격이 같지 않습니다. Cu/CCA, AWG, 피복/온도/묶음, 실제 길이와 접속을 확인합니다.

24AWG Cu 예시 R20=0.0938Ω/m이면 편도10m/1페어 왕복저항1.876Ω입니다. 0.5A에서강하0.938V/손실0.469W. 이것은 계산 예시이며 실제 자석전류나 케이블 허용전류가 아닙니다.

Rloop=2×편도길이×단심저항×온도보정/병렬페어수. 단자 접촉저항은 별도 가산합니다. +와−를 원래 페어 안에 두며, 병렬은 확인된 남는 페어만 양끝에서 대칭으로 사용합니다.

다이오드는 자석 앞이 어려우면 릴레이 근처에서 자석으로 가는 두 선 사이에 연결합니다. 줄(K)=+, 반대(A)=−. 접점 COM–NO 사이가 아닙니다. 실제 전류/열/해제시간을 확인한 뒤 1N5408 적용 또는 제너/TVS로 재선정합니다.
