상하 공간을 함께 쓰는 실제 배치

상부: 차단기·12V SMPS·PE 바·0V-PWR·부하별 퓨즈. 하부: 큰 RFID 회색함, 릴레이 A/B, Arduino, L298N, DC-DC, 0V-L, 앰프/MP3.

검토 유효 공간은 폭 400 / 상부 260 / 하부 650 / 깊이 120mm. 사진의 확정 치수가 아닙니다. 실장·치수 보기에서 실측값과 RFID 크기를 넣으면 확보 영역 조건을 비교합니다.

상하 기존 관통구에는 DC 12선 + RFID 조건부 2선을 분리 묶음으로 통과시킵니다. AC는 상부에서 끝내며, 모서리 부싱과 양쪽 고정 클립을 적용합니다.

외부 LED와 진행 버튼

액자 · 조명 · 열쇠 · RFID · 책 · 완료 중 현재 단계의 LED가 켜집니다. 프로그램 대기 중에는 해당 LED가 깜빡이고, 완료 후에는 완료 LED가 계속 켜집니다.

2초 누름 = 현재 입력 단계 1회 완료. 정상 단계와 같은 출력·음성 동작을 수행합니다. 버튼을 계속 누르고 있어도 반복되지 않으며, 기존 20초·1초·10초 대기는 유지합니다.

74HC595: D11(DATA), D13(CLK), D7(LATCH). 버튼: A3. 기존 Gun/Hint 선을 제거한 뒤 이 핀을 재사용합니다. 웹 표시등도 실제 AVR 출력으로 전송된 595 값을 표시합니다.

GND 단자대는 무엇을 쓰는가?

일반 독립 단자대 한 개가 아니라, 내부 도체로 공통 연결된 13접속점 분배블록 2개를 사용합니다. 예시: Phoenix Contact PTFIX 6/12X2,5-NS35 BU / 3273090.

0V-PWR: SMPS 음극, 전자석 3개, 모터, 앰프, 하부 로직 공통 귀환을 각각 연결합니다. 0V-L: Arduino, 센서별 기준, MP3, 릴레이 제어, 외부 LED/버튼을 각각 연결합니다.

두 블록은 굵은 0V-LINK 선으로 직접 공통 연결합니다. DC-DC GND는 하부 0V-L.11에 종단합니다. 모터·전자석 전류를 Arduino 핀·센서 GND·캐리어 PCB로 통과시키지 않는 것이 목적입니다. PE는 별도입니다.

5V SMPS를 별도로 둘까?

구성판단
12V SMPS + 5V DC-DC기본안. AC 배선·부품 수가 적고 5V를 별도 안정화. 12V 전원 장애가 로직에도 영향을 줄 수 있음.
12V SMPS + 5V SMPS대안. 12V 부하 전원 변동·고장에 대한 5V 급전 경로가 더 독립적. AC 배선·공간 증가.

5V 레일은 필요하지만 5V SMPS가 필수는 아닙니다. 단, 별도 5V SMPS를 써도 L298N·오디오·RFID의 신호 GND가 이어지면 완전 절연은 아닙니다.

센서 전원과 Arduino 신호는 별개

자석과 앰프는 확인된 12V 부하입니다. 센서와 회색 RFID 제어함은 기존 정격을 보존합니다. 모두 12V라고 가정하지 않습니다.

12V 센서도 출력이 무전압 접점/오픈컬렉터/전압출력 중 무엇인지에 따라 결선이 달라집니다. 12V 신호를 Arduino 입력에 직접 넣지 않습니다. 입력 인터페이스를 정한 뒤 S/V/0V를 종단합니다.

릴레이 A/B 두 장 모두 수용하며 B를 예비로 단정하지 않습니다. A에 4기능을 모으는 표는 채널별 기존 연결 확인을 전제로 한 조건부 배치안입니다.

기존 HW 보존 + 외부 조작부 추가

RFID 큰 회색 제어함 · 릴레이 4ch × 2장 · L298N · KT403A · HONGXING · 기존 센서/부하.

새 부품: 74HC595N, LED 6개·1.5kΩ 저항, 진행 버튼, 디바운스 부품, 내부 공통 분배블록. 기존 함수 D11/D17 제거 후 GPIO를 새 용도로 재사용합니다.

검증 범위

원본/10ms안의 시험에 더해, 외부 LED의 실제 595 래치 값·2초 버튼·누름 유지/바운스·타이머 대기·정상 센서 진행을 AVR로 시험했습니다.

MP3는 API 대역입니다. 실물 전류·전원 노이즈·접점·모터 역학·센서 인터페이스는 현장 검증이 필요합니다. 하드웨어에는 아직 업로드하지 않았습니다.
