# 3. 실장 배치

계획 유효 폭400/상부260/하부560/깊이120mm. 실측값이 아닙니다. 모터·릴레이 절연모듈/고정판을 제거하고 그 공간을 비웠습니다. 센서판/자석접속판/오디오절연판도 없습니다.

RFID 몸체160×100×65, 홍싱140×90×45는 배치 가정입니다. DDR는 위40/아래20/좌우5mm 방열 공간을 포함합니다. 도어 후면과 부품 깊이 조건은 유지합니다. 나사홀은 실물로 전사합니다.
