# v6.1 · 하네스·덕트 조립 순서

상부400×260 / 하부400×560 / 깊이120mm는 사진 기반 유효치수 가정입니다. 부품 외형·커넥터·공간 실측 후 적용합니다. 아래는 전기적 결선 변경이 아니라 기존 회로의 배선 정리 작업안입니다. 모터5V 대안은 기본 뷰에서 제외합니다.

## 덕트를 먼저 놓기
하부 왼쪽 L-PWR는 자석·모터·12V 전력, 오른쪽 L-SIG는 센서·제어 묶음의 주 경로입니다. 릴레이 위 H1은 접점 전력, 릴레이 아래 H2는 신호/5V/GND 제어 케이블, 아래 H3는 DC분배 배선입니다. 상부 U-DC와 U-PASS에서 기존 관통구로 전원 두 쌍(TRK와 홍싱 기존 어댑터)을 내립니다. 서로 다른 전원은 기계적으로 같이 지나갈 뿐 전기적으로 묶지 않습니다.

덕트 본체·커버는 기존 BOM의 동일 규격2본(각1828.8mm)입니다. [절단표](../hardware/v6/duct-cut-list.csv)의 순 길이3170mm, 절단 손실3mm 가정을 포함해1번1605mm /2번1595mm로 나눠 자를 수 있습니다. 교차·T접합부는 실물 홈/벽/덮개에 맞춰 마감하고 날카로운 단면을 제거합니다. 규격이 다른 덕트를 추가한 계획이 아닙니다. 실제 케이블 외경·유효 내경·충진율·굽힘반경은 확인 전입니다.

## 모듈의 단자를 덕트로 향하게
릴레이A/B는 접점을 H1 쪽, 제어헤더를 H2 쪽으로 놓습니다. L298·Uno 제어 단자도 H2 쪽입니다. Uno 전원헤더·L298 전원/출력 단자는 H3를 향합니다. 하부470mm 행은 왼쪽부터 P12 / P0 / 강압기 / G / 5V입니다. 로직 분배부와 Uno 몸체 간격은 도면상46.6mm입니다. MP3는 홍싱 바로 아래에 놓습니다. L298·KT403A·강압기의 실제 핀열과 모듈 회로는 대조 후 회전·앵커를 조정해야 합니다.

## 선을 모으는 순서
1. 전원 차단 상태에서 Arduino 핀·선 양끝·릴레이8채널/COM/NO/NC를 기록하고 라벨을 붙입니다.
2. 기존 AC와 PE를 보존하고 TRK-12P/TRK-0을 한 쌍으로 상부 덕트→기존 관통구→왼쪽 주 덕트→P12/P0로 정리합니다.
3. P12/P0→강압기→5V/G를 H3 안에서 연결합니다. G–P0 직접 점퍼, G→L298 추가선은 없습니다. 공통GND이며 절연 설계가 아닙니다.
4. 자석 각 회로는 급전→릴레이접점→현장+ / 현장−→P0를 한 경로에 모읍니다. 기존 꼬임쌍을 보존하고 다이오드 K(띠)=자석+, A=자석−입니다.
5. CAB-RLY는 D12/D10/D9/A4와5V/G의6가닥입니다. 전원·신호의 출발점은 각각이지만 H2에서 물리적으로 모여 릴레이 앞에서만 갈라집니다. 묶음 분기점에서 납땜하거나 전기적으로 합치지 않습니다.
6. CAB-MP3는 D2/D3와5V/G의4가닥으로 오른쪽 주 덕트→H0→MP3에 같이 갑니다. 오디오 L/R/G는 MP3에서 홍싱으로 짧게 직접 연결합니다. 홍싱 어댑터−를 추가 P0/G 선으로 연결하지 않습니다.
7. 리드 D8/D6는 신호/G 한 페어를 유지합니다. 랜케이블 외피는 입구 고정부까지 유지하고, 내부 덕트에서도 원래 꼬임쌍을 유지해 단자 가까이에서만 풉니다. A0/A1/A5는 실제 출력형식 확인 전 귀환·급전을 확정하지 않습니다.
8. CAB-MOT는 기존 D4/D5/A2 3가닥입니다. 별도 G선을 넣으면 강압기 외의 두 번째 P0–G 경로가 생기므로 이 안에서는 추가하지 않습니다. 실제 기준전압 차이·잡음은 시험해야 합니다.
9. 도어 J7는 전원2+제어4의6가닥으로 묶고 문을 최대로 열었을 때 당기거나 금속 모서리에 닿지 않는 여유를 확인합니다.

## 길이와 검사
장거리 DC·제어 구간은 공용 덕트 그래프에서 계산합니다. 모듈 단자→덕트의 노출 꼬리는 계획상 최대46.5mm입니다. 실제 선 길이는 중심선 경로에 단말 가공·작업 여유를 더해 결정하고, 여유선도 덕트 안에서 정리합니다. 실제 굽힘반경이나 여유선을 포함한 제조도는 아닙니다.

모든 도체가 묶음 표시에서 빠지지 않는지, 같은 케이블의 공통 구간, 부품·덕트 간섭, 단자 꼬리 방향, 덕트 밖 경로, 절단표2본 수량을 자동 검사합니다. 테스트에서 덕트 밖 우회와95mm 노출 꼬리는 실패하도록 확인했습니다. 실물 센서·USB·섀시 우회와 전류·전압·노이즈·온도는 별도 측정 대상입니다.
